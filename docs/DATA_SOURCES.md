# Magana Learn: data sources tracker

The one tracker for every learning material, dataset and piece of content Magana plans to use, ships, tests with or benchmarks on. It replaces the spreadsheet `Magana_Learn_Data_Sources_Tracker.xlsx` (last updated 23 Oct 2026), merged here on 24 Oct 2026.

**When you add, collect or start using something, update its row in the same commit.**

## Team rules

1. **Published benchmark and demo:** only open-licence material (CC BY / CC BY-SA), our own pages, or material with written permission.
2. **Private testing only:** materials we legitimately own. Never upload, share or publish them.
3. **Never:** pirated PDFs or unofficial past-question download sites.
4. **Credit every source.** Credit is required, but it does not replace permission for copyrighted work.
5. **No learner names, faces or personal data** in any photo. Use blank or teacher copies.
6. Licences marked **To verify** must be checked on the source page before use.
